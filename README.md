## create .env file

duplicate .env.dist in sever folder and rename it to .env

## setup MongoDB

Atlas Cloud MongoDB
Create database at https://cloud.mongodb.com
In .env file update MONGODB_URI=mongodb+srv://your-db-connection



